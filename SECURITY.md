# Security Policy

## Supported Versions

Only the latest active release and master/main branches of the **Alantec Checkmate** ecosystem receive active security updates.

| Version | Supported          |
| ------- | ------------------ |
| Sandbox | :white_check_mark: |
| Main    | :white_check_mark: |

## Reporting a Vulnerability

We take system integrity and cognitive security seriously. If you discover a security vulnerability within this repository or any of the 32 execution nodes, please follow these guidelines:

1. **Do NOT open a public GitHub issue** for sensitive vulnerabilities.
2. Send a detailed report directly to the lead architecture team at: **security@alantec.org** (or contact **Jean Laris** via verified internal channels).
3. Include a description of the issue, step-by-step reproduction steps, and potential impact.

### Response Commitment
- **Initial Acknowledgement:** Within 24 hours.
- **Triage & Assessment:** Within 48 hours.
- **Fix Deployment:** Priority hotfix on test nodes prior to production merge.
